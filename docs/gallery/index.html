Road mod gallery for SimCity 3000 Unlimited

Every piece below is built with the stock tools. The mod recognises the roads you drew and swaps in its own pieces. No new tool, no new menu item. A game without the mod opens the same city with the stock pieces. Each junction is shown alone on flat ground (the slopes on a small hill), a close-up at zoom 4 and a wider view at zoom 3.

101 junctions from the sc3mods road mod, release 2026-11-18. Select a picture to see it large and to switch between the close-up (zoom 4) and the wider view (zoom 3).

    The mods are free and come as a zip on the sc3kre releases page. The README in the zip lists every junction's off switch. Bug reports are welcome as issues on GitHub.
