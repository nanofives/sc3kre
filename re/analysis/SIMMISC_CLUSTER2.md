## 2. Notable findings (structural, highest value)

**`0x10002d0b` = the land-value / desirability AURA PROPAGATION tick — the top-priority find in this slice.** `[CONFIRMED @0x10002d0b]` This is the per-tick compute the task asked for. It is the sole consumer of the full SC3Aura.INI tunable block (`DAT_10049112`…`DAT_10049128`) that `SIMMISC.md §S12` had only seen loaded, and it wires each factor to a concrete term:
- LV base from the land layer (`param_1[0xf]`) via threshold `DAT_10049112` and two slopes derived from `DAT_10049113/14/15` `[@0x10002d0b line 38-41,63-71]`;
- pollution/education/coverage terms divided by `DAT_10049116/17/18/1a`, flag bonuses `DAT_1004911c/1d` `[@0x10002d0b line 73-88]`;
- police-coverage ladder (`DAT_1004911e/1f/20/21`) and fire-coverage ladder (`DAT_10049122/23/24/25`) `[@0x10002d0b line 89-116]`;
- three ordinance effects (`DAT_10049126/27/28`) gated by ordinance-id queries `0x15b4d1e`, `0xe2bf1e2a`, `0xe0d0722e` — these are the aura-local `NukeFreeOrdEffect / ParkingFineOrdEffect / AltDrivingOrdEffect` named in `SIMMISC.md §S14` `[@0x10002d0b line 34-36,117-125]`.
The composite is averaged over a 4×4 tile block, clamped to `[-0x7f, 0x7f]`, and written back to the output layer `param_1[0]+0x3c`; block iteration walks 16 sub-blocks with start-coordinate tables `&DAT_10049130` / `&DAT_10049134` (the same tables the aura display cursor uses in `0x1002d0b`), processing `param_1[0x2b]` tiles per call.

**Budget-layer SAVE serialiser found → the load/save pair is now complete.** `0x10007519` = `sc3_budget_layer_save` is the write counterpart to CLUSTER1's `0x10006fb0` (load): same GZCLSID `0xe11bcc69/0xa11bcc54`, same substream `0x199627`, but it *only* calls stream write methods (`+0x88`/`+0xa0`/`+0x68`) with no `operator_new`/map-insert, which resolves the direction ambiguity CLUSTER1 flagged as `[UNCERTAIN]`. It confirms the on-disk budget-object layout in full: header i64, 3× RCI records (`0x88` stride from `this+0x80`), the `this+0x5c` per-record map, annual totals, two 12-month i64 arrays (`this+0x264`, `this+0x2cc`), the bond count/`MaxBonds`×`0x1c` bond buffer (`this+0x550/0x54c`), and the `0x334/0x39c/0x46c` 12-month arrays.
