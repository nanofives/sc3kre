## 2. Notable findings (highest value)

**A per-tick effect-layer simulate — `0x1001d3f1` `sc3_effect_recompute_layers`.**
This is a full recompute pass over four data layers: zero all four, iterate the occupant list stamping each occupant's per-type footprint (`FUN_1001d840` in add mode), then run **two passes of a 3×3 box-blur** (samples at x,y offsets -4/0/+4, divides accumulator by neighbor count). The stamp deltas come from a per-type map at `DAT_10058688` keyed by occupant type (record layout: key region + 4 signed bytes at `+0x14..+0x17`). `[CONFIRMED @ 0x1001d3f1 / 0x1001d840]` This is the strongest "Simulate/EndOfMonth" candidate in the slice.

**A save/load serializer pair — `0x1003dd02` (write) / `0x1003db69` (read).**
Symmetric field lists to/from a stream object. Writer uses stream vtable `+0x88`(int)/`+0x68`/`+0x78`; reader uses `+0x38`(int)/`+0x18`(byte)/`+0x28`. Coordinates are stored as **8.8 fixed-point** (`value<<8` on write, `read<<8` on read at `local_44/40/3c`). `[CONFIRMED @ 0x1003dd02 / 0x1003db69]` Two more standalone deserializers in the slice: `0x1004350e` (variable-length record with an inline `short[]`) and `0x10042bd6` (graph datapoint, computes a signed ratio to a min/max pair).

**The 23-slot zone-developer table + a broadcast message — `0x10032848` `sc3_zone_rebuild_and_notify`.**
Confirms and extends `SIMRCI.md`: loops exactly `0x17`(23) entries at `base+0x188` stride 8 (each `vt +0x14`), rebuilds the grid with 2×2 tile-uniformity checks, then sends **message id `0x23742a09`** through the message server (`FUN_1003ceec` `+0x2c` → `+0x14`). `[CONFIRMED @ 0x10032848]`
