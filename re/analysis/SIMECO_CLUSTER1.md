## 2. Notable findings (structural)

**Save/load serialiser pair — the city-save persistence for the ecology layer.**
- **Writer `0x10006abb`** (`sc3_pollution_serialize_write`) and **reader `0x100062b4`** (`sc3_pollution_serialize_read`) are a matched pair over the same chunk: header dword `0x206c6e7c` + the main-layer GZCLSID `0xc0a81498` (the pollution-layer clsid from SIMECO.md §2). Both serialise the same fields: scalar block `this+0xcc..0x45c`, a 12-entry table at `this+0x1e8` (stride 8 dwords), the `[AgentIDModifiers]` map `DAT_10020818` (5 fields per record — same shape as the INI `%d %d %d %d %d`), and the four occupant lists at `this+0x94/0x98/0x9c/0xa0` (count-then-emit / read-count-then-rebuild).
- **The reader is version-gated**: a `ushort` version (`local_4c`) gates optional sections with `if (local_4c < 3)` and `if (local_4c < 2)` branches `[CONFIRMED @ 0x100062b4:136,308]` — so the save format has at least **3 versions**.
- **Stream magic `0xDEADBEEF`**: the read cursor ctor `0x1001799b` validates `this+8 == 0xDEADBEEF` (`-0x21524111`) and stamps `0xdeadbeef` on failure `[CONFIRMED @ 0x1001799b:79,87]`.
- **GZCOM stream primitive vtable slots** (confirms the primitives noted in commit `679a387`): write side `+0xa0`(64-bit pair), `+0x88`(dword), `+0x98`, `+0x78`(short), `+0x68`(byte), `+0x90`; read side `+0x50`, `+0x38`, `+0x28`, `+0x48`, `+0x18`, `+0x40`.
- **Secondary summary serialiser `0x100153f8`** writes a compact state block (garbage-building counters `this+0xd4/0xd8/0xdc` plus grid bounds `this+0xb8/0xb0`) after QI of clsid `0x80199683`.

**Message-id dispatch table `0x1000c54a`** (`sc3_pollution_handle_message`) — chained switch on message id `param_1[1]`: `0x605`, `0x2dcc206`, `0x2dcc25e`, `0x42f0da12`, `0xc2dcc228`. The `0xc2dcc228` case routes to `FUN_1000c763`, the pollution tile-query dispatcher already documented in SIMECO.md §3. The `0x42f0da12` case registers four items via service `this+0x30` using instance ids `0x2731/0x2732/0x2733/0x2735` in group `0x5dd`.

**Periodic / tick-adjacent entry points** (feed the tick `FUN_10008249` documented in SIMECO.md):
- `0x10007b5d` — **monthly statistics roll-up**: 12-slot ring buffer, 7 accumulator pairs rolled into 12-month arrays and summed to totals, with January (annual) and every-10th-year (decade) hooks; consumes `DAT_10020260` (MaxWaterPolluteForUI) and `DAT_1002025c` (MaxAirPolluteForUI).
- `0x10007680` — **applies queued occupant footprint changes** (four pending lists) or rebuilds the grid, then recomputes total garbage.
- `0x100095e7` — **stamps a building's pollution footprint** into the three sub-grids with a radial linear falloff `((r−d)+1)·v/(r+1)`; `param_1==0` adds, `==1` removes.
- `0x1000a032` — **occupant-type tracker**: maintains per-building-type lists + active counts by clsid (`0x4337354e`, `0x634acd1d`, `0x345777a`) under a lock.

**Tunable-key consumers confirmed** (values loaded by `FUN_100046bb`, SIMECO.md §4): incinerator `DAT_100200a0`·30 in `0x10001a22`; recycling `DAT_100201f4` in `0x10003a14`; UI-max air/water `DAT_1002025c`/`DAT_10020260` in `0x10007b5d`.

**Building-model UI query chain**: `0x10001787`/`0x10003779` (incinerator/recycling append, byte-identical bodies) → `0x10013e78` (status flags) ; and `0x10001a22`/`0x10003a14` → `0x10014279` → `FUN_1001572a`.
