## 2. Notable findings (structural, highest value)

**Budget layer lifecycle triad (S10) — fully covered:**
- **`0x10007d88` = the budget monthly tick / financial accumulator.** `[CONFIRMED @0x10007d88]` Reads the month index (`0..0xb`) from the calendar layer `(**+0x1e4)`, accumulates income/expense from every consumer layer into **twelve 64-bit buckets** (offsets `this+0x90, +0x2d0, +0x470, +0x4e8, +0x3a0, +0x268, +0x408`, each `+month*8`), and on **December (`month==0xb`)** collapses them into the annual total at `this+0x38/+0x3c`, **floors the treasury at −100000** `[@0x10007d88 line 362]`, drives the display gauge as `(treasury+100000)/1000`, and broadcasts a deficit/bankruptcy message `0x25f0a91` (and periodic `0x229a8a90`) through the message server `FUN_1002d87b`. This is the single most important sim entry in the slice.
- **`0x100067c7` = budget layer init** — zeroes the same twelve-bucket accumulator array and allocates the **bond-repayment buffer `operator_new(DAT_1004948c * 0x1c)`** (MaxBonds × 0x1c-byte records) at `this+0x54c`. This pins the per-bond record size (**0x1c bytes**) that the module map listed as `[UNCERTAIN]`, and confirms `DAT_1004948c` = MaxBonds.
- **`0x10006fb0` = budget layer save/load serialiser** (GZCLSID `0xe11bcc69/0xa11bcc54`, stream `0x199627`) — round-trips the twelve-bucket accumulator (`0x88` stride) and the MaxBonds bond records, so the save-format layout of the budget object is now mapped.

**Neighbor-deals serialiser pair + sim math (S10):**
- **`0x10014ae3` (load) / `0x10015378` (save)** — matched deserialise/serialise pair, GZCLSID `0xc2910e7d/0x82937b60`, deal records `operator_new(0x54)`, with **compass-direction opposite pairing `0↔1, 2↔3, 4↔5`** on record bytes `+0x34/+0x35`.
- **`0x1001761c` = deal offer/quantity computation** — the actual deal math: type `0..5`, `__aulldiv` by `100000`, rounds up to `DAT_10049e90[type]`, using the `[DEAL_RATE_CONSTANTS]` tunables `DAT_10049734/40/44/48/4c/50/3c` documented in `SIMMISC.md §neighbor deals`.

**Message/dispatch table:**
- **`0x1003266c` = message-text token expander** — a keyed dispatch (`switch` on a state value → resource ids `0x259‑0x260`, group `0x41f2625`) that substitutes named tokens (`DAT_1004a1a4`…) into news/message strings. This is the news-ticker/message formatter for the module.

**Aura tunable confirmation:**
- **`0x10002226` = aura layer init** independently confirms `DAT_10049110` (aura `UpdatePeriod`) from `SIMMISC.md §S12`: aura grid cell count `= (width*height)/(DAT_10049110<<4)`.

**Query/advisor family (grp `0x82e0074c`):** eight functions (`0x1000fc5d, 0x1000f49c, 0x1000d398, 0x1000da9b, 0x1001408d, 0x1001257b, 0x1000a5f0, 0x1000ae77`) share one template — pull a value from a layer by a numeric key, run a threshold ladder or ratio, and emit advisor text. Collectively they register the **data-view query-tool string table `0x82e0074c`** and the query-key set (`0x302a, 0x3016, 0x37e7‑0x37ec, 0x3872, 0x3233, 0x373c, 0x32ca, 0x3639, 0x334a, 0x37eb`).
