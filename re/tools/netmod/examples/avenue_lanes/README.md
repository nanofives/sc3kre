# avenue_lanes (task avcore)

One-way avenue halves: 2 lanes each way, one direction per half, right-hand traffic in every language (owner
2026-10-19). sc3netmod's AVL block (`re/harness/src/sc3netmod_avl.c`) writes these pieces on an avenue band it can
convert whole; any other avenue stays stock two-way. Contract and lane conventions: `re/analysis/AVENUE_LANES.md`.

- **21700** straight half (base 11204): both lanes run in the half's direction (inner lane next to the median, outer
  lane at the curb), turn matrix one-way. Written at the cell's own 11204 state.
- **21701** avenue end U-turn quarter (base 11203): the two cells of a stock end become a two-lane U-turn, outer lane
  to outer lane, inner to inner.
- **Look:** the avenue_markings white dashed lane lines (built into this folder's `art/`, see below), so a converted
  avenue looks like a stock one with the markings package.
- **Saves:** both save as their base at the same state: a game without the mod loads the stock avenue.
- **Lanes:** `avl_<id>.lanes.json`, generated by `py -3.12 -m netmod.avlanes build .` (run from re/tools with this
  folder's path); `py -3.12 -m netmod.avlanes selftest` checks them in ENGLISH and English-UK.

Build and install (the art is made from the game's own frames, so it is not shipped):

```
cd re/tools/netmod/examples/avenue_lanes
py -3.12 ../../avenue_markings.py build .            # art/11204, art/11203 (white dashes)
cd ../../../../..
py -3.12 re/tools/netmod/netpack.py install re/tools/netmod/examples/avenue_lanes --tree <game tree>
```

The game needs an sc3netmod.dll built with `sc3netmod_avl.c`. Off switch: `SC3NETMOD_AVL=0`.
