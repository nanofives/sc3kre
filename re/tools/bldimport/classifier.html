SC3 Model Classifier

Open a folder with OBJ, glTF, GLB or FBX models or Building Architect .bld files. An existing models.json is read back.

Game

not chosen
Open the models folder, choose the game folder, then Install. Close the game first. The page renders every enabled model (20 pictures each), adds them to the road mod's files in mods\netmod\overlay with backups, and keeps the building ids in sc3build\ids.json next to the models. Landmarks and civic looks go to Apps\PlugIn\bldimport, rewards to Apps\PlugIn\bldimport_rewards (they need the mods loader: sc3mods_patch -Restore moves them out for the stock game). Landmarks, rewards and civic looks can be 1x1 to 5x5, or a lot that is not square (2x3, 1x4, 4x5, up to 5 cells on each side): such a building needs the mods page row Non-square buildings on in the game, off it draws as one square over bare ground. Remove puts every file back as it was, plugins included.
No folder access (other browsers, or a game folder the browser refuses)?

The page reads the game folder (the browser asks first, nothing leaves the computer) and downloads a .zip of the files to put into it: unpack it into the game folder and let it replace files. A folder the page cannot write to also gets ids.json as a download: put it in the models folder's sc3build folder so the next install keeps the same building ids.
